# Repository instructions

- Do not add, configure, or use GitHub Actions in this repository.
- Build and verify locally with `npm run build`.
- Publish GitHub Pages manually with `npm run deploy:pages` from a clean working tree.

## Agent skills

### Issue tracker

Issues are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-role status vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. See `docs/agents/domain.md`.
